Personal Value Investing System

个人长期投资研究与决策系统

它把证据、公司研究、模型选择、情景估值、五年预期收益、冻结决策与持续复盘串成一条可解释、可质疑、可重放的链路。当前已完成阶段 1 工程底座；阶段 2 尚未启动，是明确的下一步。

定位 服务个人长期投资学习、研究、记录与复盘，不是自动交易系统。
阶段 1｜已完成 重建底座、治理文档、模板、确定性计算内核与交付闭环已建立。
阶段 2｜尚未启动 下一步建设普通非金融企业研究闭环；阶段 3、4 仍为后续规划。

Core Flow

一条从证据到复盘的主流程

先区分事实、计算、推断、个人偏好与待确认项，再让研究结论进入可冻结、可替代、可回放的决策记录。

  1. 证据
  2. 本人临时判断
  3. 公司与模型路由
  4. 三情景估值
  5. 五年预期收益
  6. 冻结决策卡
  7. 事件／季度复盘

Architecture

七层架构：先闭环，再扩展基础设施

系统以显式输入和确定性计算为基础。缺失数据必须标记，当前事实与历史时点事实隔离，冻结记录不得原地覆盖。

01

证据层

记录来源、资料截止日、公开可用日、口径与原始哈希。

02

研究层

分析商业模式、护城河、管理层、资本配置、财务质量与行业空间。

03

模型路由层

按公司经济特征选择主模型及交叉检查模型，而不是机械套用。

04

计算层

处理情景、现金流、估值、市场隐含预期、五年预期收益与敏感性。

05

决策层

承载用户判断、反方论证、冻结决策卡及新旧卡替代关系。

06

验证层

约束历史时点、股东总回报、最大回撤、基准比较与结果归因。

07

报告层

提供初学者简版与可审计详版，并共享同一输入和结果哈希。

Current Form

当前载体：轻量、透明、可验证

现阶段不急于引入数据库或自动数据平台，先验证流程、字段、公式和边界是否可靠。

Markdown

承载需求、架构、研究模板、临时判断、冻结决策与复盘记录。

JSON

承载可验证的虚构示例，以及未来模型所需的显式结构化输入。

Python 标准库

提供无外部运行依赖的确定性计算内核，避免隐藏的数据补全和环境差异。

自动化测试

保护公式、概率约束、时点资格与边界行为，并提供持续集成入口。

Scope & Meaning

首期范围与“15%”的正确含义

首期覆盖 A 股与港股

系统首先面向这两个市场建立统一研究语言与证据规则。其他市场不在当前已确认的首期范围内。

五年预期年化 15% 是研究门槛之一

这一数字用于筛查“是否值得继续研究”，必须与公司质量、估值不确定性、安全边际、关键假设和证伪条件一起判断。

它不等于指令式买卖建议，不会单独触发行动，也不是任何形式的收益承诺。
