# 模型与历史复演回归基线

## 状态

本项目当前冻结在“模型建立与回归测试”阶段。来源是用户确认的 Notion 完整 Session 纪要，以及本地只读核验的两份参考工作簿：个人价值投资与股票估值系统 V1.1、价值投资估值系统历史回测 V1.0。

## 覆盖范围

- 四条模型路线：所有者收益折现、核心现金流折现与分部加总、价值驱动企业自由现金流、银行剩余收益。
- 五年预期内部收益率、目标价格和反向增长求解。
- 历史复演 A 区冻结、B 区揭示、现金分红再投资、拆并股、基准差异和预测误差。
- `examples/regression/` 保存数值夹具，`python3 -m pvis regression` 统一执行。

## 解释边界

回归夹具用于确认公式和流程没有漂移。四家公司样本并非独立盲测，历史数字不是当前事实，不得直接生成当前估值或买卖结论。缺少口径一致的日度总回报序列时，不计算最大回撤。

## 继续开发的进入条件

继续抓取数据、建立数据库、扩大样本或开展真正盲测前，必须在 `Plan.md` 记录数据授权、时点口径、冻结规则、验收条件和用户授权。
