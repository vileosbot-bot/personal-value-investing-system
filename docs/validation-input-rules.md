## 1. 总体输入生成原则

### 1.1 形成日信息集

每个年度队列独立构造输入。只使用形成日截止前已公开的完整财年年度报告；中报、半年报和季度报告不入模，也不得用来补足完整财年序列。取形成日截止前已公开的最新完整年度报告及其之前连续五个完整财年；每份报告必须有原始公告版本、公告时间、来源文件和哈希。财务报表只允许使用 `docs/validation-data-contract.md` 规定的历史原始公告版。

- `decision_at`：预注册文件定义的形成日 23:59:59，Asia/Shanghai（UTC+8）。
- `available_at`：公告实际可供公众获取的时间；只允许 `available_at <= decision_at`。
- 形成日价格：该证券形成参考日未复权收盘价。
- 模拟执行价格：下一共同交易日开盘价；用于实现收益，不反向替代信号形成日价格。
- 统一使用截至决策时点已公开的报告；不能用后续重述值改写原始报告。

### 1.2 机械场景生成

对每个模型的主要现金流或经营指标 X，最近五个完整财年的同比增长率必须使用六个连续完整财年的水平值：X(t-5)、X(t-4)、X(t-3)、X(t-2)、X(t-1)、X(t)。六个水平值才能生成五个年度同比增长率：

g(y) = X(y) / X(y-1) - 1

只有相邻两年的 X 均为正数时才计算该年度增长率；不得对负数取 CAGR、不得加 epsilon、不得删除负增长年份。缺少六个完整年度水平值，或五个有效同比观测不足五个时，增长率输入记 NA。利润率／现金流率分位数仍使用最近五个完整财年的五个年度比率，不要求额外第六年比率。

对五个年度同比增长值按升序排列，使用线性插值分位数（Hyndman–Fan Type 7）。固定算法为：排序后得到 x(1) 至 x(n)，对分位点 p 计算 h = 1 + (n−1)p，j = floor(h)，γ = h−j；若 h 为整数则 Q(p)=x(j)，否则 Q(p)=(1−γ)x(j)+γx(j+1)。不得改用 nearest-rank、加权分位数或其他软件默认插值口径。

- 悲观：25% 分位数 \(Q_{25}(g)\)；
- 基准：中位数 \(Q_{50}(g)\)；
- 乐观：75% 分位数 \(Q_{75}(g)\)。

现金流利润率／经营利润率也使用最近五个完整年度的年度比率，按同一 Type 7 规则生成 Q25／中位数／Q75。情景配对固定为：悲观用低分位利润率与低分位增长，基准用中位数，乐观用高分位利润率与高分位增长。不得根据历史结果重新排列、调换或挑选分位数。

归一化起始现金流统一为：

\[
StartingCashFlow_s=Revenue_{latest}\times Margin_s
\]

其中 \(Margin_s\) 是上述情景对应的五年利润率分位数。若模型输入是每股现金流，再除以最新可得的稀释加权平均股数；若模型使用总额与股数两个独立参数，则保留总额和股数，不得重复除股数。

这些分位数只用于机械生成情景，不代表概率分布或未来收益概率。V1.1 模型预测期默认值（前五年稳定、后五年线性收敛至终值）保持原样。

### 1.3 缺失与异常处理

- 任何冻结函数必需输入缺失、不可比或来源无法复核时，记 NA；不使用均值、行业均值、分析师预测、供应商当前值或人为常数填补。
- 任一公司在某队列的关键输入或关键结果为 NA，该队列的前两家主组合和四家等权基线同步从主检验剔除；不对剩余公司重排、补位、替换或重新归一权重。具体诊断样本规则见预注册 §6.2 和数据契约 §12。
- RONIC 的“接近零”阈值只在本文件 §6.3 定义；累计主分母和任何辅助拆分分母共用这一同一阈值，不得在其他章节另设第二个阈值。
- 不删除经济异常值。确认录入错误时保留原始值并追加修正记录；无法确认的异常记待复核或 NA，不自行平滑。
- 不得把“不可评估”标为“不通过”，不得为了满足模型正数约束截断、取绝对值或抬高负输入。

## 2. 统一数据字典与公式

原始字段名因 A 股会计准则、港股 IFRS 报表及供应商接口而异。以下为标准化字段语义，不预设某一供应商字段名完全等同；正式实施前须逐份公告映射并双人复核。

| 标准字段 | 原始披露语义 | 统一处理 |
|---|---|---|
| `revenue` | 营业收入／收入 | 合并损益表持续经营口径；保留原币、原单位 |
| `operating_profit` | 营业利润／经营利润／EBIT | 采用报表披露值；不以 EBITDA 替代 |
| `net_profit_common` | 归属于母公司普通股股东的净利润 | 先取归属于母公司股东的净利润，再扣除当期归属于优先股的股息及永续债／其他永续资本分派；若原始净利润口径已明确排除这些分派，不重复扣除；无法区分或量化时记 NA |
| `income_tax_expense` | 所得税费用 | 使用报表当期所得税与递延所得税合计；不得与现金缴税混用 |
| `profit_before_tax` | 税前利润 | 与所得税费用同一合并范围 |
| `depreciation_amortization` | 折旧与摊销 | 现金流量表补充资料或附注；不把减值当折旧 |
| `organic_capex` | 购建固定资产、无形资产及其他长期经营资产支付的现金 | 包含建设中工程及正常生产性资产；排除企业并购、金融投资及收购子公司现金对价 |
| `operating_nwc` | 经营性净营运资本 | 经营性流动资产（剔除现金、受限现金、金融资产）减经营性无息流动负债（剔除有息借款） |
| `cash_equivalents` | 现金及现金等价物 | 排除受限资金；原币金额 |
| `interest_bearing_debt` | 短期借款、长期借款、债券及其他计息借款 | 不含贸易应付款；租赁负债单列并按规则纳入 |
| `lease_liabilities` | IFRS 16／租赁准则下租赁负债 | 仅在模型净债务和资本结构权重中按一致口径计入 |
| `ordinary_equity` | 归属于普通股股东的权益 | 排除非普通股优先资本及非控股权益 |
| `diluted_shares` | 稀释加权平均普通股数 | 使用最新完整年度报告披露值；未披露则退回期末普通股数并标记口径降级 |
| `period_end_shares` | 期末已发行普通股数（扣库存股） | 用于每股净资产，不以加权平均股数替代 |
| `dividends_declared` | 对应财年的普通股现金股息总额 | 仅计在决策时点前已公告的中期／末期股息；未公告的年度不假设 |
| `market_price` | 形成参考日未复权收盘价 | 交易所原始收盘价 |
| `market_total_return` | 市场总回报指数 | A 股使用 CSI 300 Gross TRI；腾讯使用 HSI Gross TRI；税前股息再投资 |
| `risk_free_yield` | 当地 10 年期主权债券收益率 | CNY 用中国国债；HKD 用香港政府／外汇基金 10 年期债券可比收益率 |

## 3. 折现率、风险溢价与终值增长的机械规则

### 3.1 本币无风险利率

- CNY 模型：使用形成日前最近一个可得月末的中国 10 年期国债到期收益率。
- HKD 模型：使用形成日前最近一个可得月末的香港政府／外汇基金 10 年期债券收益率；若连续性、期限或可得时点不能确认，记 NA。
- 记录来源、发布日期、观测日期、年化方式、报价单位和原始文件哈希。
- 不用美国国债收益率替代人民币或港币无风险利率。

### 3.2 本地市场 Beta 与 ERP 代理

为避免把美国 ERP 直接套用到中国或香港，本 Phase 0 使用与模型计价货币一致的本地市场历史超额收益代理。该值是历史估计，不声称是完美的前瞻 ERP。

- 市场代理：A 股 CSI 300 Gross TRI；港股 HSI Gross TRI。指数代码及数据供应商见数据契约 §11。
- Beta：以形成日前最近 60 个完整月的个股与市场月度总回报做 OLS；至少 36 个共同有效月份，否则 NA。月度回报必须同币种、含股息再投资。
- 月度无风险收益：将各月末本币 10 年期收益率 y_m 转为月有效收益 (1+y_m)^(1/12)-1。
- Beta = Cov(R_i-r_f, R_m-r_f) / Var(R_m-r_f)，不做主观调整、不缩尾。
- 历史 ERP 代理：最近 120 个有效月份的市场月度总回报减对应月度无风险收益的算术平均，年化为 ERP = 12 × mean(R_m − r_f,m)。主规则必须有完整 120 个月；不足 120 个月记 NA，不以 60–119 个月降级值替代主输入。
- **正阈值：ERP <3.00% 时记 NA 或转人工复核；ERP 本身不截断、不改写、不抬高到 3%，也不得用美国 ERP、调查值或任意常数替代。** ERP =3.00% 可进入后续公式；低于阈值的原始估计仍须保存并披露。
- 股权资本成本：Ke = Rf,本币 + β × ERP。若 Ke ≤0、关键输入缺失或估计窗口不足，模型输入 NA。

**腾讯市场选择按模型计价货币固定：**腾讯主估值现金流、SOTP 和输出均以 HKD 计价，因此主情景采用香港市场 ERP 与 HKD 无风险利率，公式为 Ke_HKD = Rf_HKD + β_HSI × ERP_HK。中国市场 ERP 配 CNY Rf 只能作为单独的敏感性情景；若计算该情景，须把现金流与估值同步转换为 CNY，并使用中国市场 Beta／ERP，不能将中国 ERP 与 HKD Rf 混用，也不能将 HK ERP 与 CNY Rf 混用。该选择依据是现金流／估值计价货币和本地市场风险匹配，不按公司注册地或投资者国籍临时切换。

ERP 是滚动历史实现值，容易受样本期影响。Ke 会传导至第五年退出值并影响隐含 IRR：茅台与腾讯的 Ke 进入权益折现率，改变第五年退出值；比亚迪的 Ke 进入 WACC 并改变第五年股权退出值；招行的 Ke 既作为剩余收益折现率，也作为 ROE 收敛终点，改变第五年退出值。regression.py 将模型第五年退出值作为 five_year_return_profile 的 exit_value，与前五年模型现金流共同求得五年隐含 IRR。因此 ERP／Ke 缺失或变动会通过退出值直接传导至隐含 IRR；不得只报告 Ke 对现值的影响而忽略该传导。

### 3.3 比亚迪 WACC

比亚迪的价值驱动模型以 FCFF 折现，使用：

\[
WACC=\frac{E}{D+E}K_e+\frac{D}{D+E}K_d(1-T)
\]

- \(E\)：形成日未复权收盘价 × 最新已披露稀释股数，形成日市场权益价值。
- \(D\)：最近已披露资产负债表的计息借款 + 租赁负债；不含贸易应付款。
- \(K_e\)：按 3.2 节 CNY CAPM 规则。
- \(K_d\)：最近三年利息费用合计 ÷ 最近三年平均计息债务（按年度平均期初、期末余额计算）；若利息费用不能从汇兑损益等财务费用中分离，记 NA。
- \(T\)：最近五个完整财年所得税费用合计 ÷ 税前利润合计；仅在税前利润合计大于零且比率在 0%–35% 内时采用。超出范围不截断、不改用法定税率，记 NA 并调查口径。
- \(D+E\) 必须为正；租赁负债在 D 与净债务中口径一致。

### 3.4 永续增长率

对使用 DCF／FCFF 的三家公司，先计算未加护栏的自然上限 g0 = min(3.0%, nominalGDP_10yCAGR)。终值计算必须满足折现率与永续增长率之差至少 2 个百分点：

- 对权益现金流 DCF，d = Ke，要求 Ke − g ≥2.00pp；
- 对 FCFF 模型，终值分母实际使用 WACC − g，因此要求 WACC − g ≥2.00pp；不得用 Ke 代替模型实际折现率。

最终 g = min(g0, d − 2.00pp)。若 g0 > d−2.00pp，触发护栏，改用 g=d−2.00pp，并记录 g_guardrail_trigger=true、g0、d、最终 g 和触发队列；不得静默覆盖。若未触发，记录 false。CNY 公司使用中国名义 GDP，腾讯主 HKD 模型使用香港名义 GDP；名义 GDP 使用形成日前已公开的最近 11 个完整年度观测。缺少 vintage、币种经济体不匹配或发布时间不清时，g 记 NA。

2 个百分点是预先固定的终值分母安全间距，不是实证发现或普遍估值定律。另报告最终 g 上下各 100bp 的敏感性；不得把终值占总价值的 60%–80% 当作默认比例。Residual Income 模型不单独输入永续增长率；其冻结结构是 ROE 在后五年线性收敛至股权资本成本。

## 4. 贵州茅台：Owner Earnings + DCF

### 4.1 冻结函数输入

V1.1 对应 `growth_dcf(starting_cash_flow, initial_growth, discount_rate, perpetual_growth)`。输入现金流为人民币／股，折现率为股权资本成本 \(K_e\)，因为 Owner Earnings 是普通股股东可得的权益现金流近似。不得把 FCFF 与 WACC 混搭。

### 4.2 Owner Earnings 可审计代理

年度 Owner Earnings proxy：

OE_y = NP_common,y + D&A_y − CapEx_organic,y − ΔNWC_Moutai,y

- NP_common：归属普通股股东净利润。
- D&A：折旧及摊销。
- CapEx_organic：购建固定资产、无形资产及其他生产性经营资产支付的现金；排除收购子公司、企业并购及金融投资。
- NWC_core：经营性流动资产（剔除现金、受限现金、金融资产）减经营性无息流动负债（剔除有息借款、租赁负债和合同负债）。

**合同负债对称处理：**ΔNWC_Moutai,y = NWC_core,y − NWC_core,y−1。合同负债增加与合同负债减少两侧都排除在 ΔNWC_Moutai 之外；不得将增加计作资金来源，也不得将减少计作现金用途。合同负债在一个周期内对 ΔNWC 的净效果为零。合同负债余额仍须单独提取并保留，用于核对和披露，但不进入 Owner Earnings 公式。若合同负债无法从其他经营性流动负债中可靠拆分，茅台该年度 OE 记 NA。

**保守性边界：**保守性体现在不计预收款浮存收益，不把合同负债增加带来的资金占用优势转化为额外 Owner Earnings；不得再使用“增加不作来源、减少作现金用途”的不对称算法。年报通常不把维护性资本开支与扩张性资本开支分开，为避免研究者主观拆分，主规则将可识别的全部有机资本开支扣除，称为 Owner Earnings proxy，不宣称等于 Buffett 定义下的精确维护性资本开支。若有机资本开支无法从并购／金融投资中分离，记 NA；不得拍一个维护性资本开支比例。

### 4.3 输入生成

- 年度 OE 利润率：\(m_y=OE_y/Revenue_y\)，要求收入为正。
- 三情景利润率：最近五年 \(m_y\) 的 Q25／中位数／Q75。
- 起始 Owner Earnings／股：最新可得年度收入 × 对应情景利润率 ÷ 稀释加权平均股数。
- 初始增长率：最近五年 OE 同比增长的 Q25／中位数／Q75。
- 折现率：CNY \(K_e\)，按第 3.1–3.2 节计算。
- 永续增长率：按第 3.4 节计算。
- 不额外把净现金加到 Owner Earnings DCF；如 V1.1 路线另有净现金加项，必须按冻结实现既有口径，不得重复计入。

OE proxy 或其利润率／增长序列不满足五年有效数据要求时，该公司—队列失效。利润率只用于生成起始现金流，不添加新模型参数。

## 5. 腾讯控股：DCF + SOTP

### 5.1 冻结函数输入与单位

V1.1 对应 `growth_dcf(..., non_operating_value=...)`。输入现金流、非经营性价值与输出均以 HKD／股计价。经营现金流使用 FCFF 口径并以 WACC 折现；非经营性净资产在 SOTP 加总时按每股金额加入。不得把已扣债务的 FCFE 再按 WACC 折现，也不得把债务重复扣减。

### 5.2 核心经营 FCFF

优先按经审计合并报表的可比经营口径构造：

\[
FCFF_y=EBIT_y(1-T_y)+D\&A_y-CapEx_{organic,y}-\Delta NWC_y
\]

- EBIT 使用持续经营合并经营利润；若合并经营利润包含投资收益、处置收益或无法分离的非经营项目，必须按附注剔除；无法核验则 NA。
- \(T_y\) 使用同一合并范围、最近五年税前利润加权有效税率；分母／税费口径不一致时 NA。
- D&A、CapEx、ΔNWC 按统一数据字典。
- 不能直接用 CFO-capex 替代 FCFF，除非能证明 CFO 中利息、税、非经营投资收益及金融业务现金流已按规则调整。
- 腾讯金融科技及企业服务业务预先划为**核心经营业务**，不得划入非经营性资产，也不得在 SOTP 中另行加值。其收入、经营利润、营运资本和资本开支应纳入核心经营口径；若金融科技业务的金融属性导致无法按同一 FCFF 定义与合并经营口径可靠核对，或分部披露不足以形成可审计拆分，该队列记 NA，不得事后改列为非经营业务。

### 5.3 三情景与 DCF 输入

- FCFF 利润率：\(m_y=FCFF_y/Revenue_y\)，最近五年 Q25／中位数／Q75。
- 起始核心经营 FCFF／股：最新可得收入 × 情景 FCFF 利润率 ÷ 稀释加权平均股数。
- 初始增长：最近五年 FCFF 同比增长的 Q25／中位数／Q75。
- 折现率：港币 WACC，按第 3.1–3.2 节港币市场规则和第 3.3 节同一公式计算；债务权重采用最近可得计息借款与租赁负债，股权权重采用形成日市值。
- 永续增长率：按香港名义 GDP 与折现率约束计算。

### 5.4 SOTP 非经营性净资产

NonOperatingValue/share =
(Cash + TermDeposits + NonOperatingFinancialAssets + EquityInvestments − Debt − Leases − NCI) / DilutedShares

**主口径选择统一账面价值：**上市及非上市股权投资均使用 decision_at 前最近已公开原始公告中的账面／账面净值；现金、定期存款、非经营性金融资产、债务、租赁负债和非控股权益也按报表账面金额计量。若某项资产在财报中已按公允价值计量，使用报表确认的账面金额，不另作研究者重估。不得在主口径中把上市投资切换为市值、非上市投资仍用账面值。

**市值敏感性（不替代主口径）：**仅对上市股权投资另算三档敏感性：持股数量 × 形成日收盘价 × (1−折价率)，折价率分别 20%、25%、30%；非上市股权投资仍用账面价值，其他项目保持主口径不变。形成日休市时使用形成日前最近交易日收盘价并记录日期。敏感性结果单独列示，不写回主 SOTP 输入，不改变冻结模型代码。

- 债务与租赁负债：最近已公开原始公告的账面余额。
- 非控股权益：若经营 DCF 为合并口径，按最近可得账面值扣除。
- 任何资产已计入核心经营 FCFF 或已作为现金流收益计入时，不得再加一次；逐项做重复计数检查。
- 账面值口径可能低于／高于形成日可变现价值；不另加流动性折价或控制权溢价，差异只作局限性披露，不事后切换口径。

如果非经营性投资、债务或非控股权益无法按上述账面价值口径分离，SOTP 值 NA，不用供应商当前持仓或后续公告回填。腾讯金融科技及企业服务业务属于核心经营，不是 SOTP 非经营性净资产。

## 6. 比亚迪：价值驱动 FCFF

### 6.1 冻结函数输入

V1.1 对应：

`value_driver_fcff(starting_nopat, shares, initial_growth, initial_ronic, discount_rate, perpetual_growth, net_debt)`

单位：NOPAT、净债务用人民币百万元／亿元的一致单位；shares 用百万／亿股的对应单位；输出为人民币／股。所有单位必须在载荷中明确，严禁将亿元与百万元混用。

### 6.2 NOPAT 与利润率

\[
NOPAT_y=EBIT_y(1-T_y)
\]

\[
T=\frac{\sum_{5y} IncomeTaxExpense_y}{\sum_{5y} ProfitBeforeTax_y}
\]

仅当五年税前利润合计为正、税率落在 0%–35%、报表合并范围一致时采用；否则 NA，不以 25% 法定税率或单年异常值替代。NOPAT 利润率 \(m_y=NOPAT_y/Revenue_y\)，三情景取五年 Q25／中位数／Q75。起始 NOPAT 为最新收入 × 对应情景利润率。初始增长率为五年 NOPAT 同比增长 Q25／中位数／Q75。

若起始 NOPAT 不为正，冻结函数会拒绝估值；不把亏损转成正数，不改模型门槛。

### 6.3 RONIC

投入资本：

IC_y = OrdinaryEquity_y + InterestBearingDebt_y + LeaseLiabilities_y − CashEquivalents_y − NonOperatingInvestments_y

**主口径为三年累计 RONIC：**

RONIC_3y,t = Σ(j=t−2…t) ΔNOPAT_j / Σ(j=t−2…t) ΔIC_j
           = (NOPAT_t − NOPAT_(t−3)) / (IC_t − IC_(t−3))

其中 ΔNOPAT_j = NOPAT_j − NOPAT_(j−1)，ΔIC_j = IC_j − IC_(j−1)。三年累计口径减少单一年度资本开支时点对比率的机械扰动；逐年 ΔNOPAT／ΔIC 仅作拆分诊断，不作为主 RONIC。

**三年累计口径示例（纯假设数字，不是比亚迪实际数据）：**四个年度 NOPAT 依次为 10、12、15、18；IC 依次为 50、54、60、66（同一货币单位）。三年 ΔNOPAT = (12−10)+(15−12)+(18−15)=2+3+3=8；三年 ΔIC = (54−50)+(60−54)+(66−60)=4+6+6=16；RONIC_3y=8/16=50%。

**唯一“接近零”定义及统一阈值：**对每一个三年窗口，定义 epsilon_IC = max(RMB 1 百万元, 1% × |IC_(t−3)|)。主累计分母 ΣΔIC，以及该窗口任何逐年拆分诊断所用的 ΔIC 分母，全部共用这一同一 epsilon_IC；不再为累计和年度口径分别设阈值。若分母绝对值 ≤epsilon_IC，记该口径 NA；主累计分母还必须为正。不得将分母截断为 epsilon、不得取绝对值、不得翻转符号。

主输入使用未截尾 RONIC_3y 原值。辅助稳健性敏感性另报告 RONIC_3y_clipped = min(100%, max(−50%, RONIC_3y))，截尾区间固定为 [−50%, 100%]；截尾值不得替代主值，也不得用于挽救近零／负分母。若原始主 RONIC_3y ≤0，冻结模型要求 RONIC>0，相关模型输入记 NA，不得用截尾值抬成正值。

**窗口数量与观测要求：**使用最近六个连续完整财年年末水平值（六个 NOPAT 水平值和六个 IC 水平值），形成三个连续滚动三年窗口：第 1–4 个年末值形成第一个窗口，第 2–5 个形成第二个窗口，第 3–6 个形成第三个窗口。至少需要三个有效窗口；三情景分别取有效原始 RONIC_3y 的 Q25／中位数／Q75。不得写成“五个年度结束点生成三个窗口”，因为五个水平值最多只能生成两个三年窗口。若三个窗口中任一有效性条件不满足，按实际有效窗口数检查；不足三个有效窗口时该公司—队列记 NA。若悲观分位数不为正，因冻结模型要求 RONIC>0，悲观情景记不可计算；不抬高到人为正值。

### 6.4 WACC、净债务与股数

- WACC：按第 3.3 节公式计算，CNY CAPM；不使用美国 ERP。
- 净债务：最近可得计息借款 + 租赁负债 − 现金及现金等价物 − 不在 FCFF 中的非经营性流动金融资产。受限现金不自动抵减债务；须单列。
- shares：最近完整年度报告的稀释加权平均普通股数；未披露时用期末普通股数并标记降级。
- 永续增长率：按第 3.4 节中国名义 GDP 规则。
- 模型内部再投资率保持冻结公式 \(ReinvestmentRate=g/RONIC\)，FCFF 保持 \(NOPAT\times(1-ReinvestmentRate)\)；不得人为修改以避免负 FCFF。

## 7. 招商银行：Residual Income

### 7.1 冻结函数输入

V1.1 对应：

`residual_income_model(beginning_book_value_per_share, payout_ratio, initial_roe, year_five_roe, cost_of_equity)`

不向银行模型强行增加 DCF 的永续增长参数。冻结结构把前五年 ROE 从初始水平线性走向第五年 ROE，再把后五年线性收敛至股权资本成本。

### 7.2 每股净资产

BVPS = OrdinaryEquity_period_end / OrdinaryShares_period_end

- OrdinaryEquity：归属于母公司普通股股东的权益，剔除优先股、其他权益工具及非控股权益。
- OrdinaryShares：同一资产负债表日已发行普通股数扣除库存股。
- 不用稀释加权平均股数替代期末股数。
- 如其他权益工具无法从普通股权益中拆分，BVPS 记 NA。
- RI 账面价值基数本来就是普通股权益除以普通股数；不改用总权益，也不把非控股权益纳入。

### 7.3 ROE 路径

ROE_y = NetProfitCommon_y / ((OrdinaryEquity_(y−1) + OrdinaryEquity_y) / 2)

- 分子 NetProfitCommon：普通股股东净利润。
- 分母为期初与期末**平均普通股权益**；该分母本来就是普通股权益，不改为总权益、平均总权益或包含非控股权益的权益。
- initial_roe：最近三个完整财年的 ROE 中位数。
- year_five_roe：最近五个完整财年的 ROE 中位数；该值是模型第 5 年的目标 ROE，不直接设为 Ke。
- 冻结模型代码依据：src/pvis/valuation.py 第 272–345 行的 residual_income_model()。第 1–5 年公式为 ROE_k = initial_roe + (year_five_roe − initial_roe) × (k−1)/4，k=1…5；因此第 2、3、4 年分别完成 25%、50%、75% 的线性过渡，并非缺失或跳过。第 6–10 年公式为 ROE_(5+j) = year_five_roe + (Ke − year_five_roe) × j/5，j=1…5；第 10 年 ROE=Ke。不得把第 5 年直接改成 Ke，不得另加收敛速度参数。
- 第 10 年 ROE=Ke 意味着第 10 年剩余收益 (ROE−Ke)×期初 BVPS 为零。冻结函数只汇总其定义范围内第 1–10 年剩余收益；没有第 10 年之后的终值项。第五年退出值按冻结函数将第 5 年期末账面价值与第 6–10 年剩余收益折现项组合，不存在“第 10 年 ROE=Ke 与额外十年后终值冲突”。
- 只使用形成日之前已公开的完整财年；正负 ROE 均保留，不能删除亏损年。
- 普通股权益为零／负数、普通股净利润归属口径不一致或五年序列不足时记 NA。

### 7.4 分红率与股权资本成本

\[
PayoutRatio=\operatorname{median}_{5y}\left(\frac{DividendsDeclared_y}{NetProfitCommon_y}\right)
\]

- DividendsDeclared：对应财年普通股现金股息总额，包括在形成日前已公告的中期与末期股息；尚未公告的股息不预测。
- NetProfitCommon：对应财年普通股股东净利润，按“归属于母公司股东净利润 − 当期归属于优先股的股息 − 当期归属于永续债／其他永续资本的税后利息或分派”计算；若永续债利息已作为损益表利息费用扣除，或原始披露净利润已经明确是普通股股东口径，则不得重复扣除。优先股股息或永续资本分派金额无法识别、期间无法匹配或是否已扣除无法确认时记 NA，不用估算值。
- 至少三个有效财年；中位数须在 0–1，否则记 NA，不截断至 0 或 1。
- `cost_of_equity`：按第 3.1–3.2 节 CNY \(K_e\) 计算。
- 不用净息差、信用成本、拨备覆盖率等经营指标直接改写冻结模型的 ROE 输入；这些指标可作为风险诊断，不作为本模型额外参数。

## 8. 人工不可规则化输入与盲化隔离协议

### 8.1 原则

主验证信号不允许由看过结局的人手工拍增长率、利润率、RONIC、ROE、WACC、终值增长率或非经营资产价值。上述参数必须按本文件公式生成。人工只可处理原始报表字段到标准数据字典的映射，不得决定数值大小。

下列项目如不能从公开资料机械分离，必须记 NA，而不是让分析员主观估计：

- 茅台维护性资本开支：年报不单列时，按第 4.2 节扣除全部可识别有机 CapEx；有机 CapEx 无法拆分则 NA。
- 腾讯核心经营 FCFF 与 SOTP：经营／金融业务、投资收益、非经营性资产或少数股东权益无法按第 5 节分离时 NA。
- 比亚迪 RONIC：投入资本、税率或历史增量资本回报数据不足时 NA。
- 招行普通股权益、股息或 ROE：优先／其他权益工具无法拆分时 NA。
- 本地风险溢价、因子、汇率、指数总回报：历史 vintage 或时间戳缺失时 NA。

### 8.2 谁执行、谁复核、谁保管结局

- **输入执行人**：运行冻结脚本、采集形成日前原始公告、按字段映射表生成输入；不得访问 B 区结果库、后续行情或已揭示的队列结果。
- **独立复核人**：A 区冻结前复核公告时间、单位换算、字段映射、公式和 A 区输入哈希，不得接触 B 区；A/B 数据快照哈希均生成并封存、B 区由结果保管人正式解封后，独立复核人可在首次评估前复核 B 区结果数据、实现回报、NA 事件、HH 方差与临界值复算。独立复核人不得参与输入生成，也不得在 B 区解封前读取 B 区。
- **结果保管人**：独立保存未来财务、行情、公司行动和基准数据；在 A 区封存前不得向输入执行人或复核人披露。
- 若无法找到独立执行人与结果保管人，或执行人已读过该队列结果，队列只能标记为“历史信息集约束复演”，不得标记真正盲测。

### 8.3 人工字段映射审批

任何会影响模型输入的字段映射（例如“资本开支”是否含收购、某项金融资产是否属于经营资产、某项权益是否属于普通股权益）须：

1. 先写映射规则和反例；
2. 由两人对照原始公告及附注复核；
3. 在首次处理该队列前冻结映射规则版本；
4. 记录原文页码、附注编号、单位、原始值、标准化值及 SHA-256；
5. 若形成日后发现映射错误，只能追加修订记录；不得静默覆盖原始值。

人工不得直接覆盖模型数值。确有无法规则化且仍希望研究的变量，只能作为“探索性旁证”，由未接触结局的独立分析员在决策截止前签名并封存；该变量不进入主验证信号，也不能使缺失的主输入变为合格。

每个公司—队列的 A 区 JSON 至少包含：

A 区哈希生成后只允许追加审计日志，不允许修改原载荷。B 区只有在独立保管人确认 A 区哈希和冻结时间后才可解封。

**排序与精确并列裁决：**组合排序使用冻结模型输出的未四舍五入 five_year_irr 原始精度值，由高到低排列；若原始存储精度下完全相等，按固定 security_id 升序裁决并列。不得使用展示值四舍五入后的数值、V/P、MOS、公司名称或后续实现回报进行二次排序。该规则只确定监测队列的排序，不改变 V1.1 模型输入、函数或参数；并列标记须写入 A 区载荷。

- `entry_price` 固定为形成参考日收盘价 P，与 V/P 和 MOS 使用同一价格；下一共同交易日开盘价只用于实际模拟成交和实现回报。
- 茅台与腾讯的 `five_year_return_profile()` 年度现金流来自冻结 DCF 的模型预测现金流；比亚迪来自 FCFF／股；招行来自 Residual Income 模型生成的预测每股股息。这些现金流是 V1.1 的模型定义，不代表公司承诺派发的实际现金股息。
- `five_year_irr` 是冻结模型现金流和形成日收盘价推导的**模型隐含毛 IRR**。当前冻结函数不接收佣金、印花税、滑点、股息税或执行价格，因此该信号本身不扣交易成本。实际样本外组合收益必须另按数据契约，在下一交易日开盘成交、持有期公司行动、股息再投资和退出交易中扣除成本。
- `target_entry_price` 使用冻结函数默认 `target_rate=0.15`，只表示在模型预测现金流不变时达到 15% 毛 IRR 的数学价格；它是模型毛 IRR 的研究诊断值，不是买入指令，不代表扣成本后的 15% 净 RMB 组合 CAGR，也不是 15% 目标已实现或方法有效的证据。
- 不得把茅台／腾讯／比亚迪的模型现金流改成实际历史股息，也不得为了让隐含 IRR 与实现回报更接近而调整现金流定义。实际股东总回报与模型隐含 IRR 的差异正是待检验对象之一。

- Ke／WACC 对隐含 IRR 的传导必须单独披露：five_year_return_profile 接收前五年模型现金流及模型第五年退出值；Ke 通过茅台／腾讯折现率、比亚迪 WACC、招行剩余收益折现率及第 6–10 年 ROE 向 Ke 收敛路径，改变第五年退出值，进而改变五年隐含 IRR。不得把第五年退出值视为与 Ke 无关，也不得在计算 IRR 时用内在价值替代第五年退出值。

## 10. Phase 0 规则与 V1.1 冻结模型的关系

| 项目 | 冻结输入规则 | 对冻结模型的影响 |
|---|---|---|
| 增长率 | 最近五个年度同比增长的 Q25／中位数／Q75 | 只填 initial_growth，不改函数 |
| 现金流／NOPAT 利润率 | 最近五年比率分位数 × 最新收入 | 只生成 starting_cash_flow 或 starting_nopat |
| WACC／Ke | 本币 Rf + 本地 Beta × 本地 ERP；ERP <3% 为 NA；腾讯主 HKD 情景匹配 HKD Rf 与香港 ERP | 只填折现率 |
| 永续增长率 | min(3%、名义 GDP CAGR、实际模型折现率−2pp)；触发时记录护栏 | 只填 DCF／FCFF 永续增长参数 |
| 茅台合同负债 | 增加与减少两侧都排除在 ΔNWC 外；不计浮存收益 | 只影响 Owner Earnings proxy 输入规则 |
| 腾讯 SOTP | 主口径所有股权投资统一账面价值；上市投资市值折价 20%／25%／30% 仅敏感性 | 主输入仍按冻结函数 non_operating_value |
| 比亚迪 RONIC | 三年累计 ΣΔNOPAT／ΣΔIC 为主；统一 epsilon_IC；[−50%,100%] 截尾仅敏感性 | 只填 initial_ronic，不改函数 |
| 招行 ROE | 平均普通股权益作 ROE 分母；BVPS=普通股权益／普通股数；第 1–5 年线性过渡、第 6–10 年收敛至 Ke | 只填银行 initial_roe、year_five_roe、beginning_book_value_per_share |
| 公司行动／股数 | 交易所公告及报告披露值；腾讯分派京东／美团作为衍生持有资产 | 只提供模型输入和回报重建数据 |

本规则不能改变 growth_dcf、value_driver_fcff、residual_income_model、five_year_return_profile 的代码、默认十年预测结构或数值校验。若机械输入不能满足冻结函数的正数／区间约束，记录模型无法估值，不得绕过约束。

### 10.1 本文件在预注册监测中的边界

本文件只负责按冻结 V1.1 规则机械生成形成日输入；模型输入、模型估值与五年隐含毛 IRR 不因本次监测定位修订而改变。2027 年起的前瞻年度队列使用这些冻结输出形成排序；排序精度与精确并列裁决按本文件 §9 执行，该裁决不修改模型输出。实际五年净 RMB 回报按数据契约重建；所有指标只作描述性监测。15% 目标、模型 target_entry_price 与五年隐含毛 IRR 不是同一个口径，均不得写成确认性通过。唯一重大失败停止规则见预注册 §6.2，不得通过修改本文件输入规则影响停止判断。
