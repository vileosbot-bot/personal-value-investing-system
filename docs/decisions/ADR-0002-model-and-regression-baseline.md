# ADR-0002：项目状态对齐到模型建立与回归测试

日期：2026-09-02
状态：已接受

## 背景

原重建计划将项目停在最小计算底座，下一步才准备普通非金融企业模型。用户随后明确说明：GPT Session 已多轮修改并回退到“模型建立和回归测试”状态，本地项目也必须达到该状态。

## 决策

以用户当前修正和 Notion 完整 Session 纪要为最高优先级，在不引入数据库、自动抓取或外部运行依赖的前提下，实现四条冻结模型路线、五年预期收益、反向求解、严格 A／B 区历史复演和数值回归夹具。

## 后果

- 原“阶段 1 完成、下一步才建模型”的状态被本决策替代。
- 四家公司只作为模型调试与防漂移样本，不声称独立盲测或统计有效。
- 未来扩样、实时数据和前端均不自动进入当前范围。
