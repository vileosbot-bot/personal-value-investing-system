- Request ID：\`pvis-phase0-design-20261113-01\`
- 版本：Phase 0 / v0.1（设计稿，待验收；未采集、未验证）
- 适用范围：600519.SH、00700.HK、002594.SZ、600036.SH；形成截面 2016–2021，前瞻保留 2027。
- 状态原则：本文件定义字段、来源优先级、时点和缺失规则；不表示任何数据源已经成功下载、获准长期存储或完成历史 PIT 验证。

## 1. 数据对象与强制字段

每一条财务、行情、公司行动、宏观、汇率或因子记录必须保存：

| 字段 | 定义 |
|---|---|
| \`entity_id\` | 公司及证券唯一标识；A/H 股分开记录证券代码 |
| \`field\` | 标准化字段名，如 revenue、operating_profit、cash_from_operations、capex |
| \`value\` / \`unit\` | 原始数值与原始单位；不得先四舍五入再入库 |
| \`period_start\` / \`period_end\` | 财务期间或行情期间 |
| \`published_at\` | 发行人／交易所公告的原始发布时间 |
| \`available_at\` | 本系统认定该记录可供决策使用的时间，含时区 |
| \`decision_at\` | 所属形成截面的信息截止时间 |
| \`source_name\` / \`source_url\` | 原始发布方与可复核链接 |
| \`source_document_id\` | 公告编号、文件编号或交易所文件 ID |
| \`version_type\` | original、corrected、restated、vendor_current 等 |
| \`retrieved_at\` | 实际抓取时间 |
| \`raw_sha256\` | 原始 PDF／HTML／CSV／响应体哈希 |
| \`parser_version\` | 解析器版本及代码 commit |
| \`quality_status\` | raw、parsed、cross_checked、blocked；不得自行标 VERIFIED |

所有财务数字同时保留原始披露值和标准化值。标准化不能覆盖原始字段；每项转换须保存公式、输入字段和单位。

## 2. 时点与公告规则

### 2.1 主规则

\`available_at <= decision_at\` 是唯一资格条件。按公告实际公开时间判断，不按报告期末、财务年度结束日、新闻转载日、供应商数据库最后更新时间或研究人员下载日判断。

- A 股：使用上交所／深交所／巨潮资讯及发行人官网的公告原始时间；统一记录北京时间 Asia/Shanghai（UTC+8）。
- 港股：使用 HKEXnews 披露易原始发布时间；记录香港时间 Asia/Hong_Kong（UTC+8）。
- 若有精确时分秒，按原始时间入库。形成时点是 23:59:59，因此当日盘后、且在截止前发布的公告可进入 A 区。
- 若只拿到公告日期而没有时间，保守地将 \`available_at\` 设为该日期之后的下一共同交易日 09:30（当地时间）；不得假定盘中或盘后具体时间。
- 新闻报道、供应商摘要、当前网页内容不能代替原始公告；只作为查找线索。

### 2.2 5 月 1 日兜底

5 月 1 日只允许作为中国 A 股年度报告法定披露截止日的有限兜底标记，并且必须同时满足：公司没有发布延期／变更披露时间公告；交易所公告检索与公司公告目录已核对；研究对象是年度报告而非中报或季度报告。

- 有延期公告：不得使用 5 月 1 日；使用延期后实际公告的时间。
- 实际年报已经在 5 月 1 日前发布：使用实际公告时间。
- 截至 5 月 1 日仍查不到年报原件，或是否延期无法确认：记为 missing / pending，不得仅因日历到了 5 月 1 日就伪造“已披露”。
- 对港股年报不套用 A 股 5 月 1 日规则；按港交所披露期限、延期公告和实际披露时间处理。

## 5. 原始版、重述版与修订链

每个报告期至少区分：

1. \`original\`：首次正式披露版本；历史形成截面只允许使用该版本（且 \`available_at <= decision_at\`）。
2. \`corrected\`：公司或交易所更正公告；记录更正时间和替代字段。
3. \`restated\`：后续重述或追溯调整版；只用于事后误差归因或敏感性分析，不回写历史 A 区。
4. \`vendor_current\`：供应商当前数据库值；只作核对，不能证明历史当时可知。

如果原始版本找不到、只有后续重述版，历史输入记为缺失。不可用今天的财务数据库数值回填 2016 年输入。每次更正均保留旧文件、旧哈希、新文件、新哈希及影响字段。

## 6. 价格、公司行动与股东总回报

### 6.1 原始价格

主记录使用未复权开、高、低、收、成交量、停牌状态和交易所代码。供应商前复权／后复权序列仅作核对，不作为唯一证据，因为供应商可能按当前已知公司行动重写整个历史序列。

### 6.2 现金分红

- 记录公告日、股权登记日、除息日、派息日、每股税前股息、币种、代扣税和实际到账日。
- 总回报主序列采用税前现金股息再投资；再投资时点统一为除息日收盘价，以与总回报指数的除息日再投资假设对齐。
- 再投资股数：\`新增股数 = 当前股数 × 每股可再投资股息 / 再投资价格\`；再扣除再投资买入佣金、适用税费与滑点。
- 税后敏感性将可分配股息替换为税后金额，不覆盖税前主序列。

### 6.3 送股、转增、拆股与合并

按生效日调整股数乘数与每股价格，保存原始公告。送股／转增／拆股不能作为现金分红再次计入；同一公司行动不得重复调整。

### 6.4 配股、供股、分拆与特殊分派

配股／供股需要记录认购比例、认购价、缴款时间和权利价值；分拆需记录分派证券数量与可观察价格。若没有足够数据重建现金流和权利价值，该持有期总回报标记为缺失，不假设“免费参加”或“放弃后价值为零”。退市现金对价、清算分配和最后交易价格按公告记录，不向前填充价格。

## 7. 幸存者偏差与历史成分

- 本轮固定四家公司且它们在设计时仍上市，样本有明显的事后选取限制。不能用幸存者偏差的 0.5%–1.5%/年统一扣减来“修复”。
- 对四家公司本身，保留其退市风险、停牌、公司行动及证券类别变化；不得因后续表现差而删掉队列。
- 若未来获批扩展股票池，必须按每个形成日的历史上市公司全集、历史指数成分、历史行业分类、ST／停牌状态建池；纳入已退市、破产、被收购公司及其最终回报。禁止用当前成分股名单回建历史样本。
- 0.5%–1.5%/年只作为特定文献样本的敏感性参考，不作为本研究的统一修正系数。

## 8. 复权、币种与汇率

### 8.1 本币计算

- 贵州茅台、比亚迪、招商银行：CNY。
- 腾讯：HKD。
- 个股信号、个股 CAGR、个股基准超额先在本币计算；组合与 15% 目标统一换算为 RMB。

### 8.2 RMB 组合回报

腾讯每个计价日按同一来源的 HKD/CNY 日汇率换算。组合每日净值先计算本币股票及现金流，再换算为 RMB；不得只用起点／终点汇率而忽略中间股息再投资现金流。若只有月度汇率，月度组合结果可以另报，但不得伪称日频精确值。

### 8.3 汇率数据

优先官方或授权来源：CFETS／中国外汇交易中心、国家外汇管理局、香港金融管理局。使用日度中间价或可交易收盘价须在预注册冻结时选定一种；不同口径作为敏感性单独报告。历史时点与数据授权待核实。

## 9. 股息税与指数税口径

- 主 15% 指标为个人所得税前，但交易环节税费照常计入；同时输出税后敏感性。
- 对**内地个人投资者通过沪港通／深港通持有港交所上市 H 股**，按适用政策对股息红利按 20% 代扣个人所得税；该规则不能无差别应用于所有港股投资者、所有税务居民或其他持有渠道。
- 若投资者身份／持有渠道不明确，至少报告 0% 与 20% 两个股息税情景，并标记税后结果待核实；不得把 20% 当作所有投资人的普遍税率。
- A 股个人股息税涉及持有期限和投资者身份，不能统一套用一个税率；税前总回报和按具体规则计算的税后回报分开保存。
- CSI 300 全收益指数反映税前股息再投资；净收益指数采用指数规则中的 10% 股息税假设。主基准用全收益，税后敏感性可用净收益，但必须说明指数税率与个人实际税率不一定相同。
- 恒生 Gross TRI 使用税前股息，Net TRI 使用税后净股息；主基准用 Gross TRI，税后敏感性用 Net TRI，并核对其税率假设。

税务依据入口：国家税务总局财税〔2016〕127 号深港通税收政策，关于内地个人投资者 H 股股息 20% 代扣见 https://fgk.chinatax.gov.cn/zcfgk/c102416/c5203646/content.html 。后续政策变更须按每个历史派息日的有效规则记录。

## 11. 基准与因子数据

- CSI 300 全收益与净收益的计算方法不同：全收益使用税前现金红利再投资；净收益采用指数规则中的 10% 税率。主基准选择全收益指数。
- 恒生指数公司分别发布 Gross TRI 与 Net TRI；Gross 使用税前股息，Net 使用税后股息；主基准选择 Gross TRI。
- A 股 FF5+MOM：优先北京大学公开中国 A 股因子序列，字段 MKT、SMB、HML、RMW、CMA、MOM。公开说明到 2023-12；2024–2026 覆盖未核实。缺失月份不外推。
- 腾讯因子：优先寻找香港本地 FF5+MOM；若未找到，可将 Kenneth French Asia Pacific ex Japan 因子作为明确标注的区域代理敏感性，统一转换到同一回报币种后估计；不得称为香港本地因子。
- Open Source Asset Pricing 的 CRSP/WRDS 数据是美国市场，不用于填充 A/H 因子。
- FF5+MOM alpha 按 A 股与港股分市场报告。没有同一可比因子序列时，不汇总一个“整体 A/H alpha”。

## 12. 缺失值、异常值和停止规则

- 缺数写 \`NA\`，并填写缺失原因、来源查询记录、尝试日期和责任人；不使用均值、行业均值、分析师预测或供应商当前值补齐。
- 原始公告无法获取、公告时间无法确定、重述版本无法拆分、关键公司行动缺失、币种无法统一或基准序列不完整时，该队列相应指标停止计算。
- 不删除异常值。若确认录入错误，保留原始值并追加修正记录；若确为经济异常，原样保留并报告稳健性。
- 任何数据供应商的接口条款、商业使用、缓存、存储、再分发限制未确认前，不批量抓取、不将受限原始数据提交到 GitHub。
- 不提交 API Token、Cookie、账户凭据或个人身份资料。需要付费积分、商业订阅或额外授权时，先停下并单独取得用户授权。
